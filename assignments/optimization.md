# Overview
this exercise is about following instructions that don't provide much detail. There isn't a huge amount of work for you to do; the challenge is figuring out exactly what to do. You will often encounter problems like this in life.

**This is an individual assignment. You are meant to write the code on your own. You are welcome to discuss *ideas* with other students (including on the class email list), but don't look at their code or show them yours.**

# Quantization
1. In a Google Colab notebook, reproduce the "first look at a neural network" MNIST classification model from chapter 2. Feel free to cut and paste code from the book's notebooks.

2. After training, quantize the network to use 8-bit integers for inference. This is one short line of code!

3. Determine whether the quantized model takes less memory.

4. Determine whether the quantized model is approximately as accurate as the original model.

# Optional Challenge Problems

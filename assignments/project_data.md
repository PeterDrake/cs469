# Data

Now it's time to actually acquire data for your project. Assuming you are doing supervised learning, you will need *inputs* and "correct" *labels*.

Depending on the project, the data may be a CSV file, images, or text. You might find a single large dataset or have to combine several.

Make a directory on BLT in one of your accounts. Put the data in there, as well as a Python program that reads the data (into, for example, a pandas dataframe, a tensor, or a keras dataset) and prints some statistics (e.g., the shape of the dataset) and somehow displays a single example.
